#

## Learn gab in 10 minutes

This tour covers the core concepts of gab, more in depth than we've seen so far.
The tour assumes some familiarity with programming, but no prior experience with gab or any particular programming paradigm.

At the end of the tour, you will understand all the features of the language. With this understanding,  you should have a clear idea of what gab programs look like. 

Before navigating the tour, it is recommended to install gab and follow along in the REPL. If you want to skip the tour, take a look at the example programs!
